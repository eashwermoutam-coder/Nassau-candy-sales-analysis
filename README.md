#  Nassau Candy Sales Analysis

## Project Overview
This project focuses on analyzing Nassau Candy sales data using Microsoft Excel and Power BI. The objective is to understand sales performance, identify trends, evaluate product performance, and generate meaningful business insights through data analysis and interactive dashboards.

## Project Objectives
- Analyze overall sales performance.
- Identify top-performing products and categories.
- Understand regional sales distribution.
- Analyze sales trends and patterns.
- Generate insights to support business decision-making.

##  Tools & Technologies
- **Microsoft Excel:** Data cleaning, data preparation, and analysis.
- **Microsoft Power BI:** Data visualization, interactive dashboards, and reporting.

## Key Analysis
- Overall sales analysis.
- Product-wise sales performance.
- Category-wise sales analysis.
- Regional sales performance.
- Sales trends and business insights.
- Key Performance Indicators (KPIs).

## Project Dashboard
The Power BI dashboard provides interactive visualizations to explore sales performance, product trends, and regional insights.

## Key Learnings
- Practical experience in data cleaning and analysis.
- Understanding business sales metrics.
- Creating interactive dashboards using Power BI.
- Improving analytical and problem-solving skills.
- Converting raw data into meaningful business insights.
